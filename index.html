Распознавание еды

Работает из России без VPN. Бесплатно, до 50 фото в день.

  1. Откройте openrouter.ai/settings/keys и войдите через Google или почту.
  2. Нажмите Create API Key, придумайте любое имя, нажмите Create.
  3. Скопируйте ключ (начинается с sk-or-) и вставьте ниже.

Нужен включённый VPN: из России Google не пускает. Бесплатный лимит больше.

  1. С включённым VPN откройте aistudio.google.com/apikey и войдите в Google.
  2. Нажмите Create API key.
  3. Скопируйте ключ (начинается с AIza) и вставьте ниже.
Дополнительно

Оставьте как есть, если не уверены. Пустое поле вернёт модель по умолчанию.

Ключ хранится только на этом телефоне. Фото отправляются выбранному сервису только для оценки.

Получится ссылка, которая сразу настроит распознавание с этим ключом. Отправьте её только тому, кому доверяете: лимит 50 фото в день будет общим.
